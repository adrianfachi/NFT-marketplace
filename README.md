# NFT-marketplace

Marketplace de NFTs criado para explorar coleções digitais, consultar detalhes
das obras e experimentar fluxos de cadastro, carteira e carrinho de compras.
O projeto oferece uma demonstração interativa com dados e operações simulados.

## Deploy

Acesse a aplicação: [nft-marketplace-adrian.netlify.app](https://nft-marketplace-adrian.netlify.app/)

## Mais informações

O setup, os comandos, as variáveis de ambiente e as instruções detalhadas estão
na pasta [`frontend`](./frontend), incluindo o [README da aplicação](./frontend/README.md).
